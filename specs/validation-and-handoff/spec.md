# Spec

## 배경

AI coding agent와 함께 작업하려면 테스트 결과, 변경 기록, ADR, 다음 작업 요청이 분리되어 보여야 한다. 사용자는 작업이 완료됐는지, 어떤 위험이 남았는지, 어떤 결정을 승인했는지 확인해야 한다.

## 요구사항

- 테스트 화면은 최신 테스트 결과를 위에서부터 보여줘야 한다.
- 변경 기록 화면은 최신 변경 로그를 위에서부터 보여줘야 한다.
- 결정 기록 화면은 ADR 목록과 결정 내용을 보여줘야 한다.
- 작업 완료 시 변경 범위, 검증, 위험, 후속 작업을 기록할 수 있어야 한다.
- 계획 탭 기능 카드가 `specs/validation-and-handoff/` 경로와 연결되어야 한다.

## 범위

- 포함:
  - 테스트 기록 화면
  - 변경 기록 화면
  - ADR 화면
  - 작업 후 로그 기록
  - 기능 계획 카드의 handoff 상태 표시
- 제외:
  - 자동 테스트 실행 UI
  - Codex API 직접 연동
  - GitHub PR 자동 생성

## 사용자 또는 downstream 영향

- 비개발자는 Codex 작업이 어떤 검증을 거쳤는지 확인할 수 있다.
- AI coding agent는 완료 보고 형식과 변경 로그 기준을 유지할 수 있다.

## 데이터 계약 영향

- 테스트, 로그, ADR 표시용 내장 데이터를 사용한다.
- 새 저장소나 외부 연동은 추가하지 않는다.

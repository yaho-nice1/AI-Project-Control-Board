# Acceptance Tests

## 완료 기준

- 보드는 브라우저에서 `src/index.html`을 열었을 때 바로 표시된다.
- 워크플로우 단계는 `AGENTS.md`, `spec.md`, `plan.md`, `tasks.md`, `acceptance-tests.md`, `change-log.md`, `adr/` 흐름과 연결된다.
- 각 단계에는 관련 파일 경로, 검토 질문, 완료 조건이 표시된다.
- 체크리스트 선택 상태가 새로고침 후에도 유지된다.
- AI 작업 지시문에는 작업 전 확인 문서, 변경 가능 파일, 완료 보고 형식이 포함된다.
- `./scripts/run_tests.sh`가 통과한다.

## 자동 테스트

```bash
./scripts/run_tests.sh
```

## 수동 검증

- 보드에서 각 단계를 선택했을 때 상세 패널이 바뀌는지 확인한다.
- 문서 라이브러리에서 핵심 템플릿 문서의 목적과 검토 질문을 확인한다.
- 체크리스트를 선택하고 새로고침한 뒤 상태가 유지되는지 확인한다.
- AI 지시문 복사 버튼 또는 텍스트 선택 복사가 가능한지 확인한다.

# Change Log

## 2026-06-03

### 변경 내용

- 요구사항 홈, 칸반 보드, 왼쪽 내비게이션, 작업 태스크 맵을 workflow visualization 기능 spec으로 분리했다.
- 작업 탭에서 기능 노드의 `FEATURE n`, 진행률, 문서 수 표시를 제거하고 기능 제목 중심으로 단순화했다.
- 기능별 태스크 노드를 작은 클릭형 카드로 바꾸고, 작업 상세는 하단 고정 영역 대신 팝업으로 표시하도록 변경했다.
- 작업 탭 연결선을 가로 리스트형 선에서 기능별 1:N 마인드맵 선 구조로 보정했다.
- 작업 탭 연결선을 CSS pseudo-element 방식에서 SVG path 방식으로 전환해 노드 위치 기준으로 자연스럽게 그리도록 변경했다.
- 기능별 task 목록을 기본 접힘 상태로 바꾸고, 기능 노드 클릭 시 해당 기능의 task만 펼치도록 변경했다.
- 요구사항 홈의 완료/현재/다음 단계 카드를 고정값이 아니라 실제 기능, 문서, task 상태 기준 진행률로 계산하도록 변경했다.
- 홈 작업 보드를 개별 task가 아니라 실제 기능 상태 기준 칸반으로 동기화했다.

### 변경 이유

- 화면 흐름과 작업 시각화는 제품 전체 spec이 아니라 독립 기능으로 추적해야 한다.
- 작업 탭의 목적은 기능과 태스크의 연결 관계를 빠르게 보는 것이므로, 노드 내부의 보조 정보와 하단 상세 리스트는 시각적 흐름을 방해한다.
- 태스크가 여러 개인 기능은 한 줄 연결보다 기능에서 각 태스크로 분기되는 1:N 구조가 관계를 더 명확하게 보여준다.
- CSS 선은 카드 크기와 반응형 배치가 바뀔 때 쉽게 어긋나므로, 마인드맵 연결은 노드 위치를 계산한 SVG path가 더 안정적이다.

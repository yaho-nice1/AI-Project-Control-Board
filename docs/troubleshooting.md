# 트러블슈팅

## 목적

자주 발생하는 문제와 해결 방법을 정리한다.

## 문제 목록

### 보드가 비어 보인다

확인할 내용:

- `src/app.js`가 로드됐는지 확인한다.
- 브라우저 개발자 콘솔에 JavaScript 오류가 있는지 확인한다.
- `src/index.html`에서 `app-root` 요소가 있는지 확인한다.

해결 방법:

1. `./scripts/run_tests.sh`를 실행한다.
2. `node --check src/app.js` 오류를 확인한다.
3. 최근 수정한 보드 데이터의 쉼표, 괄호, 따옴표를 확인한다.

### 체크리스트 상태가 예상과 다르다

확인할 내용:

- 같은 브라우저에서 실행 중인지 확인한다.
- `localStorage`에 이전 상태가 남아 있는지 확인한다.

해결 방법:

1. 보드의 초기화 버튼으로 체크 상태를 지운다.
2. 문제가 반복되면 `ChecklistItem.id` 중복 여부를 확인한다.

### 복사 버튼이 동작하지 않는다

확인할 내용:

- 브라우저가 Clipboard API를 지원하는지 확인한다.
- 파일 직접 실행 환경에서 권한이 제한됐는지 확인한다.

해결 방법:

1. 프롬프트 패널의 텍스트를 직접 선택해서 복사한다.
2. 정적 서버 환경에서 다시 확인한다.

## 새 문제 기록 방식

문제가 반복되면 원인, 재현 방법, 해결 절차를 이 문서에 추가한다.

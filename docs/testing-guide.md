# 테스트 가이드

## 목적

테스트 명령어와 변경 유형별 필수 테스트를 정의한다.

## 기본 명령

```bash
./scripts/run_tests.sh
```

## 변경 유형별 필수 테스트

| 변경 유형 | 필수 테스트 |
| --- | --- |
| 화면 구조 변경 | HTML/CSS 수동 검증, smoke test |
| JavaScript 동작 변경 | `node --check`, smoke test |
| 데이터 계약 변경 | 문서 계약 갱신 확인, smoke test |
| 템플릿 문구 변경 | 관련 문서 경로와 보드 데이터 일치 확인 |
| 문서 상태 동기화 변경 | `node scripts/board-sync.js`, `./scripts/run_tests.sh`, 브라우저 새로고침 확인 |
| 배포 방식 변경 | 로컬 파일 실행, 정적 서버 실행 확인 |

## 수동 검증

자동 테스트로 확인하기 어려운 항목은 `specs/<feature-name>/acceptance-tests.md`에 수동 검증 절차와 결과를 기록한다.

## 실패 시 처리

1. 실패 테스트 이름과 원인을 기록한다.
2. 문서 변경 때문인지 화면 구현 변경 때문인지 구분한다.
3. 보드 데이터 문제라면 연결된 템플릿 파일 경로와 문구를 함께 확인한다.

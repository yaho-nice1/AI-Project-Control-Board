# 데이터 품질 규칙

## 목적

보드 데이터와 템플릿 문서 연결의 품질 기준을 정의한다.

## 기본 품질 기준

| 항목 | 기준 | 실패 시 조치 |
| --- | --- | --- |
| 문서 연결 | 모든 단계는 실제 파일 경로를 가져야 한다 | 보드 데이터와 spec 갱신 |
| 체크리스트 | 각 단계는 1개 이상의 검토 항목을 가져야 한다 | 누락 항목 추가 |
| 상태값 | 단계 상태는 허용값 안에 있어야 한다 | `docs/data-contracts.md` 확인 |
| 프롬프트 | AGENTS 규칙, spec, plan, tests가 포함돼야 한다 | 프롬프트 생성 로직 갱신 |

## 검증 항목

- 누락된 템플릿 경로 수:
- 중복된 체크리스트 ID 수:
- source가 없는 단계 수:
- 완료 기준이 비어 있는 단계 수:

## 기록 위치

기능별 품질 검증 결과는 `specs/<feature-name>/acceptance-tests.md` 또는 `change-log.md`에 기록한다.

# ADR-0001: 로컬 우선 정적 보드 사용

## 상태

채택됨

## 맥락

비개발자가 AI 프로젝트 템플릿을 사용하려면 설치, 서버 실행, 터미널 명령이 진입 장벽이 된다. 첫 버전은 템플릿 흐름을 이해하고 AI 작업 지시문을 만들 수 있는 보드가 핵심이다.

## 결정

초기 버전은 빌드 도구와 백엔드가 없는 로컬 우선 정적 웹앱으로 만든다. `src/index.html`, `src/styles.css`, `src/app.js`만으로 실행하고, 체크리스트 상태는 브라우저 `localStorage`에 저장한다.

## 결과

긍정적 영향:

- 별도 설치 없이 브라우저에서 바로 실행할 수 있다.
- 템플릿 문서와 화면의 대응 관계를 빠르게 검증할 수 있다.
- AI 지시문 생성과 비개발자 검토 흐름에 집중할 수 있다.

부정적 영향 또는 트레이드오프:

- 실제 Markdown 파일을 직접 수정하는 기능은 아직 없다.
- 여러 사용자 동시 협업과 권한 관리는 후속 설계가 필요하다.
- 브라우저 로컬 상태는 기기 간 자동 동기화되지 않는다.

## 검토한 대안

- Next.js 기반 대시보드
- Electron 데스크톱 앱
- GitHub 저장소와 직접 연동하는 웹 서비스
